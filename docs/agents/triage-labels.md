# Labels de triagem

Os skills falam em termos de cinco papéis canônicos de triagem. Este arquivo mapeia esses papéis para as strings de label usadas de fato no tracker deste repo.

| Label em mattpocock/skills | Label no nosso tracker | Significado                                |
| --------------------------- | ----------------------- | ------------------------------------------- |
| `needs-triage`              | `needs-triage`          | Precisa ser avaliada                        |
| `needs-info`                | `needs-info`            | Esperando mais informação de quem reportou  |
| `ready-for-agent`           | `ready-for-agent`       | Totalmente especificada, pronta pra um agente AFK |
| `ready-for-human`           | `ready-for-human`       | Exige implementação humana                  |
| `wontfix`                   | `wontfix`                | Não será tratada                            |

Quando um skill menciona um papel (ex: "aplicar o label de pronto-pra-agente"), use a string de label correspondente desta tabela.

Edite a coluna da direita se algum dia o vocabulário de labels deste repo mudar.
